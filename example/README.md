# still example

A gallery for the four motion decisions: Platform, Full, Reduced, and Off. It opens in English. The language menu switches the whole screen to Portuguese.

Open **The proposal** to read why the package exists. In Portuguese the same button is **A proposta**. The panel uses `StillTransition` and `StillStagger`, so changing the mode and opening it again shows the difference.

```bash
flutter run -d macos
flutter run -d chrome
```

`lib/previews.dart` exposes the same entrance under widget previews, so the three effects can be checked without booting the gallery.
